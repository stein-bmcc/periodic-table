How to read a card

The top row shows a typical display or role and an example parent or context. These are teaching shortcuts, not complete HTML content rules. CSS can change how an element is displayed.

The bottom row shows opinionated typical website usage (common, less used, or uncommon) and a learning priority: 1 for foundational, 2 for next steps, and 3 for specialized uses. An asterisk marks document fundamentals. Usage labels reflect an opinion about typical websites, not measured statistics. Learning priorities are not requirements from the HTML standard.

Filters overlap. Core is an introductory selection; Core Text and Core Media focus on those topics. Page Structure identifies regions and page-level interfaces; Setup covers document configuration. Interactive includes links, disclosures, dialogs, and the listed form controls. Form covers forms, labels, controls, and field groups.

Cards follow the filter order by their color group: neutral All-only reference entries, Setup, Page Structure, Core, Core Text, Core Media, Interactive, then Form. Elements in both Interactive and Form stay together at the end with the Form color. Card colors and positions stay the same when filtering.

Examples are source code, not live demonstrations. Replace sample file paths and server endpoints when using them. This table is a curated introduction, not an exhaustive list of HTML elements.

Definitions and examples

<dl>

The dl groups terms and their descriptions or other name-value associations.

Source: MDN: <dl> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<dl>
  <dt>Mulch</dt>
  <dd>A covering that protects the soil.</dd>
</dl>
Back to the elements

<dt>

The dt identifies a term or name in a description list.

Source: MDN: <dt> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<dl>
  <dt>Compost</dt>
  <dd>Decayed organic material used to improve soil.</dd>
</dl>
Back to the elements

<dd>

The dd supplies a description or value associated with a preceding term in a description list.

Source: MDN: <dd> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<dl>
  <dt>Seedling</dt>
  <dd>A young plant grown from a seed.</dd>
</dl>
Back to the elements

<blockquote>

The blockquote identifies an extended quotation from another source.

The cite attribute records a source URL but does not display a visible attribution by itself.

Source: MDN: <blockquote> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<figure>
  <blockquote cite="https://example.org/garden-guide">
    <p>Healthy soil supports a healthy garden.</p>
  </blockquote>
  <figcaption>From <cite>The Garden Guide</cite></figcaption>
</figure>
Back to the elements

<pre>

The pre preserves spaces and line breaks in its text.

Escape HTML markup when displaying it as code. Pair pre with code for a block of source code.

Source: MDN: <pre> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<pre><code>&lt;p&gt;Hello, garden!&lt;/p&gt;</code></pre>
Back to the elements

<table>

The table presents data with relationships expressed through rows and columns.

Use tables for tabular data, not page layout. Supply a caption and associate headers with data cells.

Source: MDN: <table> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

  <caption>Seeds planted this week</caption>
  <thead>
    <tr><th scope="col">Crop</th><th scope="col">Packets</th></tr>
  </thead>
  <tbody>
    <tr><th scope="row">Peas</th><td>3</td></tr>
    <tr><th scope="row">Beans</th><td>2</td></tr>
  </tbody>
  <tfoot>
    <tr><th scope="row">Total</th><td>5</td></tr>
  </tfoot>
</table>

DOCTYPE declaration

The doctype declaration tells browsers to use standards mode. It is a required document preamble, not an HTML element.

Place it before the root html element. The short HTML doctype does not select a numbered HTML version.

Source: MDN: DOCTYPE declaration by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<!doctype html>
Back to the elements

<html>

The html element is the document root and contains the head and body.

Set lang to the language of the page so browsers and assistive technology can interpret it correctly.

Source: MDN: <html> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <title>Community garden</title>
  </head>
  <body>
    <h1>Community garden</h1>
  </body>
</html>
Back to the elements

<head>

The head contains document metadata, including the title, character encoding, and resource links.

Do not confuse head, which supplies metadata, with header, which introduces visible content.

Source: MDN: <head> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Community garden</title>
  <link rel="stylesheet" href="styles.css">
</head>
Back to the elements

<title>

The title names the document for browser tabs, bookmarks, and other contexts.

Use a descriptive title that distinguishes this page from other pages on the site. It is separate from the visible h1.

Source: MDN: <title> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<head>
  <meta charset="utf-8">
  <title>Planting calendar | Community garden</title>
</head>
Back to the elements

<meta>

The meta element supplies metadata that other dedicated metadata elements do not express.

Declare UTF-8 early in head. Keep the viewport scalable; do not disable user zoom.

Source: MDN: <meta> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<meta charset="utf-8">
<meta name="description" content="Planting dates for our community garden.">
<meta name="viewport" content="width=device-width, initial-scale=1">
Back to the elements

<link>

The link element describes a relationship to an external resource, such as a stylesheet.

For stylesheets, rel="stylesheet" identifies the relationship and href identifies the file.

Source: MDN: <link> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<link rel="stylesheet" href="styles.css">
Back to the elements

<style>

The style element contains CSS for the document.

Use an external stylesheet when the same rules are shared by multiple pages.

Source: MDN: <style> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<head>
  <title>Garden notes</title>
  <style>
    .notice { font-weight: bold; }
  </style>
</head>
Back to the elements

<script>

The script element embeds or loads executable code or a data block.

Module scripts are deferred by default. Keep behavior in a separate file rather than inline event attributes.

Source: MDN: <script> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<search>

The search groups controls or content used to search or filter information.

It identifies a search region; it does not implement searching or replace a form’s submission behavior.

Source: MDN: <search> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

    <label for="query">Search garden notes</label>
    <input id="query" name="q" type="search">
    <button type="submit">Search</button>
  </form>
</search>

<b>

The b element draws attention to text without adding importance or stress emphasis.

Use CSS font-weight when the reason is only visual styling.

Source: MDN: <b> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<p>Bring <b class="keyword">gloves</b> and a <b class="keyword">trowel</b>.</p>
Back to the elements

<em>

The em element marks stress emphasis that can change the meaning of a sentence.

Source: MDN: <em> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<p>Please water the seedlings <em>before</em> lunch.</p>
Back to the elements

<i>

The i element distinguishes an alternate voice, technical term, or other text conventionally offset from ordinary prose.

Use CSS font-style when italics are purely decorative.

Source: MDN: <i> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<p>The botanical name is <i lang="la">Solanum lycopersicum</i>.</p>
Back to the elements

<br>

The br element creates a line break where the break is part of the content.

Use paragraphs and CSS spacing for layout, not repeated br elements.

Source: MDN: <br> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<p>Green leaves grow<br>Under the morning sunlight</p>
Back to the elements

<ul>

The ul represents a list whose item order is not significant.

<li>

The li represents an item in a list.

Put li inside ul, ol, or menu, not directly inside a generic div.

Source: MDN: <li> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<ul>
  <li>Carrots</li>
  <li>Peas</li>

<time>

The time marks a time or date that can have a machine-readable representation.

Use a valid datetime value when the visible text does not already have the required machine-readable format.

Source: MDN: <time> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<mark>

The mark identifies text that is relevant in the current context.

Use em for stress emphasis and strong for importance; mark indicates contextual relevance.

Source: MDN: <mark> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<p>Search result: Plant <mark>tomatoes</mark> after the last frost.</p>

<code>

The code identifies a fragment of computer code.

For multiple lines, nest code inside pre. Escape angle brackets when showing HTML source.

Source: MDN: <code> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

The hr represents a thematic break between parts of the content.

Use CSS borders for lines that are purely decorative.

Source: MDN: <hr> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

<figure>

The figure groups self-contained content that can be referenced from the surrounding text.

<figcaption>

The figcaption supplies a caption for the content of its parent figure.

Put one figcaption first or last within its figure. A caption does not automatically replace image alternative text.

Source: MDN: <figcaption> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<figure>
  <img src="garden.jpg" alt="Raised beds beside a greenhouse">
  <figcaption>The garden in early spring.</figcaption>
</figure>
Back to the elements

<img>

The img embeds an image in the document.

Provide alt text that serves the image’s purpose. Use alt="" for a purely decorative image; include dimensions to reserve layout space.

Source: MDN: <img> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<img src="seedlings.jpg" alt="Three tomato seedlings in pots" width="640" height="480">
Back to the elements

<video>

The video embeds a video player in the document.

Provide captions for spoken audio and other meaningful sounds, plus descriptions of essential visual information when needed. Avoid autoplay.

Source: MDN: <video> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<video controls width="640">
  <source src="planting.mp4" type="video/mp4">
  <track kind="captions" src="planting-en.vtt" srclang="en" label="English" default>
  <p><a href="planting.mp4">Download the planting video</a>.</p>
</video>
<p><a href="planting-transcript.html">Read the transcript</a>.</p>

<audio>

The audio embeds an audio player in the document.

Provide an equivalent transcript and let the listener start playback.

Source: MDN: <audio> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

<audio controls>
  <source src="garden-tour.mp3" type="audio/mpeg">

<picture>

The picture supplies alternative image sources for different formats or presentation needs.

Include a fallback img with appropriate alt text. The img supplies the image’s text alternative, not the source elements.

Source: MDN: <picture> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

Example HTML

  <source srcset="garden.webp" type="image/webp">
  <img src="garden.jpg" alt="Volunteers planting a raised bed" width="640" height="480">
</picture>

<source>

The source supplies alternative media resources for picture, audio, or video.

Use srcset for a source inside picture and src for a source inside audio or video.

Source: MDN: <source> by Mozilla Contributors. Summary adapted for this table under CC BY-SA 4.0.

<track>

The track supplies timed text, such as captions, for audio or video.

Caption files use WebVTT. Captions include speech and meaningful sounds; subtitles commonly translate speech.
